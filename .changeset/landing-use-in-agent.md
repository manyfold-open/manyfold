The landing hero's second button is now "Give your agent Manyfold", marked with the Claude Code and Codex icons, in place of "Read the docs". One click copies the same setup prompt the workspace's "Use Manyfold in your agent" dialog copies, and the button turns into "Paste it into your agent" with a check mark, so a visitor can hand their own coding agent Manyfold without signing up first. Where the clipboard is unavailable it links to the guide instead. It shows for signed-in visitors too, and stays hidden while the sign-up gate is on. The FAQ answers how to do it, and the sign-in page tells someone sent there by `mf login` that their agent is asking to connect and that approving comes next.
