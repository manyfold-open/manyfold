The CLI sign-in page now covers sign-ins that an AI agent starts, not only a command typed in a terminal. The title, description, code check, one-time-code hint, expiry and error messages mention the terminal or the agent, and the page title reads "CLI sign-in". The safety note tells users to close the page if neither they nor their agent just started a sign-in. All 11 interface languages are updated.
