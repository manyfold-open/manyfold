Agent settings on a cloud computer now show Environment, Connections, Context and MCP, the same as on a sandbox. The platform already delivers all four there through the host's daemon; the settings rail was still hiding them. A service agent (OpenClaw, Hermes) on a cloud computer also gets the Restart button and the pending-restart reminder after an environment change, as the restart endpoint already allowed. The "available on …" notes, which now appear only for external agents, name cloud computers as well.
