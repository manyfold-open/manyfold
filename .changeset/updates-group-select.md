Select or clear a whole group at once in the Update Center. Each group heading now has a checkbox that selects every update in that group that can be run from the page, and shows when only part of the group is selected; the table's select-all checkbox shows the partial state too. Selecting a collapsed group leaves it collapsed.

A selected update that can no longer be run from the page, such as one on a machine that just went offline, now drops out of the selection instead of staying checked and counted. In right-to-left languages, table headings, group headings, the Update Center's action column and the Group by menu now line up on the reading side, and a collapsed group's arrow points the right way. The Japanese label of the Update selected button no longer contains a Simplified Chinese character.
