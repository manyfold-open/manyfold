Claude Code turns now freeze the provider route they were dispatched on, the way Codex, Gemini CLI, pi and Antigravity CLI turns already do. A resumed run whose CLI reports the session's running total is priced from its own tokens under that verified provider and managed brand, including after an API restart re-attaches to it, instead of under no brand at all. Usage is attributed to a provider only when the turn carried that provider's key to its endpoint; a run on the CLI's own sign-in is no longer attributed to the Agent's saved provider.
