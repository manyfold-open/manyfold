The create form's sandbox cards show only the frameworks the sandbox has; the rest are installed from the card's "…" menu ("Install OpenClaw", or "Check sandbox" before it was ever probed). A framework's menu and the runtime page's header both use the same version control as the sandbox page: click the version to change it, and follow the arrow to the Update Center when a newer one is out. The create form reads the version out of the CLI's own output, so Claude Code and Codex no longer read "v2.1.251 (Claude Code) · Latest" when a newer release is out. The runtime page's Change version dialog is gone.
