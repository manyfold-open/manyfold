## `mf ui resolve`

Resolve an automation or the automations list to a web URL

**用法:** `mf ui resolve [options] <resource> [id]`

**Argument**

| 参数 | 用途 |
| --- | --- |
| `<resource>` |  |
| `[id]` |  |

**Option**

| Option | 用途 |
| --- | --- |
| `--run-id <id>` | resolve the conversation of this automation run |
| `--json` | output resource links as JSON |
| `-h, --help` | display help for command |
