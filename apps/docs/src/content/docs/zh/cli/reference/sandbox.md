## `mf sandbox storage-usage`

Report cached current-sandbox storage; --account reports the whole account

**用法:** `mf sandbox storage-usage [options]`

**Option**

| Option | 用途 |
| --- | --- |
| `--json` | output the result as JSON |
| `-h, --help` | display help for command |
