# 使用工作区

工作区是你与 Agent 对话并检查其工作的位置。每个 Agent 都有自己的聊天会话、文件、终端访问、skills 和设置。

## 聊天

使用聊天来下达任务、审查结果和补充指令。好的 prompt 通常包含：

- 目标。
- Agent 需要检查的文件、仓库区域或系统。
- 约束条件，例如 "do not commit" 或 "explain before editing"。
- 期望输出，例如 patch、摘要、清单或测试结果。

对于较长任务，可以要求 Agent 给出进度更新和验证步骤。

## 文件

使用文件浏览器检查 Agent 工作区。Coding agent 可以在会话中读取和修改工作区里的文件。

请把 source of truth 文件保存在仓库或已连接的存储中。生成文件在你审查前都应视为工作草稿。

## 终端

终端提供对 Agent 工作区的直接访问。你可以用它运行检查、查看命令输出或调试设置问题。

命令会在所选 Agent 的工作区中运行。对删除文件、轮换凭证或修改外部服务的命令要谨慎。

## 会话

会话可以恢复。你可以离开一个任务，之后再回来，从同一个对话和工作区状态继续。

当工作目标不同，或不应该共享上一个线程上下文时，请使用单独会话。

## Skills

Skills 是可复用的说明和工作流，可以安装到支持的 Agent 上。当你希望 Agent 按固定流程执行审查、发布说明或领域排障时，可以使用 skills。

从工作区或设置区域打开 **Skills**，安装 skill，然后在聊天中要求 Agent 使用它。

## 用量

打开 **Settings -> Usage**，按时间范围、Agent 和提供方查看模型用量与费用。如果某个任务费用异常或方向不对，请停止运行，并在重试前检查提供方和模型设置。

## 良好使用习惯

- 从小任务开始，等 Agent 理解上下文后再扩大范围。
- 发布前审查代码和文件。
- 把凭证放在提供方设置或渠道设置中，不要写进 prompt。
- Agent 在网页工作区表现稳定后，再接入团队渠道。
- 不再需要的 Agent 或运行环境应及时删除。
